# 🌱 Smart Agriculture Management System

An AI-powered web application developed using **Python Flask** to help farmers manage agricultural activities efficiently.

## 📌 Project Overview

Smart Agriculture Management System is a web-based application that helps farmers manage farming activities digitally. The system provides crop management, farmer management, AI-based disease detection, soil analysis, fertilizer recommendations, weather information, and agriculture news on a single platform.

## ✨ Features

- 👨‍🌾 Farmer Management (Add, Edit, Delete, Search)
- 🌾 Crop Management
- 🍂 AI Leaf Disease Detection
- 🌱 Soil Analysis
- 💧 Fertilizer Recommendation
- 🌦 Weather Information
- 🌿 Crop Recommendation
- 📰 Live Agriculture News
- 📊 Reports Dashboard
- 🔐 Admin Login System
- ❌ Custom 404 Error Page

## 🛠 Tech Stack

- Python
- Flask
- SQLAlchemy
- SQLite
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
